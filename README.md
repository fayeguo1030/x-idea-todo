# X 待办

把 X 上的一条帖子或评论，转成待办。

适用 x.com 和 twitter.com。与 X 无关。

## 做什么

在帖子下方点「记成待办」。输入框里是原话的第一句，改成要做的事再回车，或直接回车保存原话。同一条再点，会显示「已记成待办」，不会再记一条。

打开工具栏图标看列表。还没做的排在前面，最久的在最上面。时间显示「今天」或「N 天」。放下满 48 小时还没完成，写成「已放 N 天」，图标上出现数字。

点「完成」后，这条收进「已完成」。点错了，展开后点「撤回」。

「我的关注」里可以加人、搜索、拖动排序，每人最多 3 个标签。帖子上已加入的作者会显示「已关注」。

数据只存在这个浏览器里，不上传。

## 本地加载

1. 打开 `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本目录。

改了 `manifest.json`，或改了 X 页面上的脚本之后：在扩展卡片上点刷新，再刷新已经打开的 X 页面。只改弹窗里的文件时，重新点一次工具栏图标即可。
